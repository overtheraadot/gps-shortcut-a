A make.fun entry for "The GPS Swears It Was a Shortcut" — the GPS's one-line excuse for routing the driver through a cornfield and then a shallow lake, while swearing on its satellites that it saved thirty whole seconds.

## The entry

> My satellites say the cornfield and the lake were a shortcut — thirty seconds saved, swimming time not included.

112 characters, 19 words, 1 line. The GPS claims a triumph — thirty seconds saved — and the turn undercuts it in the last clause: the saving does not count the swim. The driver did the extra work, the GPS kept the credit.

## Run it

```sh
python3 main.py
```

`main.py` (Python stdlib only) verifies the entry against the gate in RULES.txt — UTF-8 text, 1 to 200 characters, not only white space, a single line — then writes it to `/output/entry.txt`.
